# UX and accessibility

Responsive routes: `/`, `/learn`, `/learn/[track]`, `/learn/[track]/[lesson]`, `/news`, `/news/[slug]`, `/search`, `/about`, `/sources`, `/login`, `/admin/sources`, `/admin/review`, `/admin/runs` and fallback /404, /loading, /error. `/ask` is P1 unless schedule permits.

Brand direction: trustworthy, documentation-first, generous whitespace, readable Vietnamese fonts, mobile bottom nav or collapsible sidebar, clear reading progress and last verified date. Avoid invented content filler. State Coming soon, not broken 404 for syllabus modules. Use semantic landmarks, keyboard focus, text contrast, aria names, code overflow accessible, link new tab safety. SEO title/description/OG/robots/sitemap/canonical; robots disallow admin/private content; never index draft. Test at 320px/768px/desktop and keyboard only.
